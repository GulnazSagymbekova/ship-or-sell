# Ship-or-Sell: финансовая модель (B2C)

Одна модель для README, питча и слайдов. Рынок из Census, остальное **[допущение]**.

## Себестоимость

| Статья | На переезд | Основание |
|---|---|---|
| Claude (распознавание ~10 фото + ~5 объявлений) | ~$0,45 | цены Anthropic: Sonnet 5.5 $2 / $10 за 1 млн токенов, ~1,5¢ за фото, ~0,4¢ за объявление |
| Stripe | 2,9% + $0,30 с платежа | stripe.com/pricing |
| Хостинг | ≈ $0 на демо-объёмах | Vercel, Supabase |

AI тратится на каждого бесплатного пользователя тоже, поэтому валовая маржа считается на всех: **~80%** на Pass, ~90% на Home+.

## Допущения

| Параметр | Значение |
|---|---|
| Free → платный тариф | 10% [допущение, верхняя граница] |
| Pass / Pro | 70% / 30% → средний чек **$44** |
| Платящие, которые остаются на Home+ после триала | 30% [допущение] |
| Отток Home+ | 3% в месяц → ~33 месяца, **~$136** чистыми на подписчика |
| CAC на пользователя (органика: 50% SEO, 30% подпись в объявлениях, 20% реклама Meta) | ~$1,85 [допущение] |

## LTV / CAC

| Что продаём | LTV на пользователя | LTV/CAC (органика) | LTV/CAC (только Meta, ~$6,3) |
|---|---|---|---|
| Только Pass $29 | $2,3 | 1,3 ❌ | 0,4 ❌ |
| Pass + Pro | $3,8 | 2,0 ❌ | 0,6 ❌ |
| **Pass + Pro + Home+** (как в продукте сейчас) | **$7,9** (≈ $79 на платящего) | **4,3 ✅** | 1,3 ❌ |

**Честный вывод для жюри:** разовый платёж сам по себе не окупает привлечение. LTV > CAC в 4 раза получается **за счёт подписки Home+ и органического роста** (SEO-страницы «стоит ли везти диван из X в Y», подпись «Priced with Ship-or-Sell» в каждом объявлении). Платная реклама в Google не окупается: клики там перекупают муверы.

Состав $104M на 5-й год (агрессивный): **Home+ $76M** (1,27 млн подписчиков ≈ 1% домохозяйств США), **Pass/Pro $17M**, **комиссии магазинов $11M** (3% Amazon с мебели на замену, которую человек сам покупает по ссылке; без них $94M).

Что держит $100M: Home+ должен выйти за пределы переезжающих (опись для страховки нужна всем). В агрессивном сценарии ~1,1 млн подписчиков пришли не из переезда. Это главное допущение, его надо назвать самим. Настоящий recurring — это Home+, 73% выручки на 5-й год.

**Про комиссии:** ссылка на магазин — это покупка самого человека, магазин платит нам 3% (Amazon Associates, официальная ставка). Мы ничего не продаём бизнесу. Без комиссий модель даёт $94M.
