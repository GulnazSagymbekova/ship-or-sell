# Источники данных

## `src/data/zips.json` — ZIP → { lat, lng, city, state }

- 41 906 ZIP-кодов США (50 штатов, DC, PR и территории; военные APO/FPO — `AA`/`AE`/`AP` — исключены, как и ZIP без координат).
- Источник: npm-пакет [`zipcodes`](https://www.npmjs.com/package/zipcodes) v8.0.0 (BSD License, © 2007 Dav Glass),
  данные которого взяты с [federalgovernmentzipcodes.us](http://federalgovernmentzipcodes.us/) (свободный справочник ZIP США).
- Преобразование: оставлены только поля `lat`, `lng` (4 знака), `city`, `state`; ключ — 5 цифр с ведущими нулями; JSON без пробелов (~3 МБ).
- Координаты — центроид ZIP; дистанция в `src/lib/zips.ts` — haversine × 1.2 (приближение дорожной).

## `src/data/category-defaults.json` — типичные размеры и вес по категории

Типичные W×D×H (дюймы) и вес (фунты) средней вещи категории, по каталогам массовых ритейлеров (IKEA, Wayfair, West Elm): трёхместный диван, угловой диван, кровать и матрас queen, комод на 6 ящиков, стол на 6 персон, ковёр 8×10 футов, торшер и т. д. Используется для ручного добавления вещи и как запасной вариант в pricing.

## Ставки в `src/lib/pricing/index.ts`

Оценки по открытым прайсам 2025–2026: межштатный мувер ≈ $0.75/фунт на 1000 миль (считают 7 фунтов на куб. фут), контейнер PODS-типа ≈ $3.7/куб. фут на 1000 миль, аренда грузовика в одну сторону + топливо ≈ $2.2/куб. фут на 1000 миль. Доли перепродажи б/у мебели: ДСП ~12% от новой, массив ~40%, известные бренды держат цену лучше.
