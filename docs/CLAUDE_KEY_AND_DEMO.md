# Ключ Claude API и демо-режим

> Для всей команды. Как устроено распознавание фото и объявления, зачем нужен ключ,
> как его получить и что делать, если ключа нет.

---

## Зачем нужен ключ

Две функции продукта делает не наш код, а модель **Claude** (`claude-sonnet-5-5`) через API компании Anthropic:

| Функция | Эндпоинт | Что делает Claude |
|---|---|---|
| Распознавание мебели | `POST /api/analyze` | смотрит на фото и возвращает список вещей: категория, название, материал, состояние, размеры, вес |
| Объявление для Marketplace | `POST /api/listings` | пишет заголовок и текст объявления по атрибутам вещи |

API Anthropic платный: каждый запрос подписывается **API-ключом** (`sk-ant-…`). По нему Anthropic понимает, чей это запрос и с какого баланса списать деньги. Без ключа эти две функции работать не могут.

Всё остальное (переезды, загрузка фото, ручное добавление вещей, расчёт `/api/estimate`, paywall, оплата) от ключа **не зависит**.

## Сколько стоит

Цены Claude Sonnet 5.5: **$2 за 1 млн входных токенов, $10 за 1 млн выходных.**

| Действие | Примерно | Стоимость |
|---|---|---|
| Распознать 1 фото (1600×1200 + промпт) | ~3 500 токенов на вход, ~800 на выход | **~1,5 цента** |
| Сгенерировать 1 объявление | ~600 на вход, ~250 на выход | **~0,4 цента** |

**$5 хватает примерно на 300 распознаваний.** На разработку, тесты и демо обычно уходит 50–150 фото, то есть $1–2.

Точный расход: https://console.anthropic.com/usage

### Защита бюджета (уже в коде)

| Лимит | Значение | Что будет при превышении |
|---|---|---|
| Распознаваний на пользователя в час | 30 | `429` |
| Объявлений на пользователя в час | 20 | `429` (уже сгенерированные отдаются из кэша и лимит не тратят) |
| **Всего вызовов Claude в сутки** | `AI_DAILY_LIMIT`, по умолчанию 500 (~$7,5) | демо-режим, если включён, иначе `503` |

Счётчики хранятся в таблице `ai_calls` в Postgres, а не в памяти сервера.
Вход у нас анонимный, поэтому часовой лимит обходится очисткой кук. **Бюджет защищает именно суточный лимит.** Хочешь жёстко уложиться в $5 — поставь `AI_DAILY_LIMIT=200` (≈ $3 в сутки).

## Как получить ключ

1. Зарегистрируйся: https://console.anthropic.com (письмо с подтверждением может попасть в «Спам» или «Промоакции»).
2. Пополни баланс на $5: https://console.anthropic.com/settings/billing
3. Создай ключ: https://console.anthropic.com/settings/keys → **Create Key** → имя `ship-or-sell` → скопируй (начинается с `sk-ant-`). Ключ показывается **один раз**.

Если регистрация не проходит — попроси ключ у кого-то из команды или у организаторов хакатона. Ключ можно создать в чужом аккаунте специально для проекта.

### Куда вставить

**1. Локально — файл `.env.local`** в корне проекта (в VS Code, не в терминал):

```
ANTHROPIC_API_KEY=sk-ant-...
```

Сохрани (Ctrl+S) и перезапусти `npm run dev` (Ctrl+C → `npm run dev`).

**2. На проде — Vercel:**
https://vercel.com/gulnazsagymbekova/ship-or-sell/settings/environment-variables
→ **Add Environment Variable** → Key `ANTHROPIC_API_KEY`, Value `sk-ant-…`, Type **Secret** → Save →
https://vercel.com/gulnazsagymbekova/ship-or-sell/deployments → ⋯ у верхнего деплоя → **Redeploy**.

### Безопасность ключа

- **Не вставляй** ключ в чат, в терминал, в код и в переменные с префиксом `NEXT_PUBLIC_`.
- **Не показывай** `.env.local` на скриншотах.
- Ключ засветился → https://console.anthropic.com/settings/keys → удали его (Delete) и создай новый, обнови `.env.local` и Vercel.
- В Claude уходит только то, что нужно: для распознавания — **только изображение**; для объявления — атрибуты вещи, цены, **название** города отправки и дата переезда. Никогда — email, имя, userId, ZIP, адрес.

## Демо-режим (`DEMO_FALLBACK`)

Страховка на случай, когда Claude недоступен: нет ключа, кончились деньги, сбой сети, исчерпан суточный лимит.

### Как включить

В `.env.local` **и** в Vercel (тип Config):

```
DEMO_FALLBACK=true
```

Локально — перезапусти `npm run dev`. В Vercel — Redeploy.

Выключить — `DEMO_FALLBACK=false`.

### Что происходит в демо-режиме

| Ситуация | `DEMO_FALLBACK=false` | `DEMO_FALLBACK=true` |
|---|---|---|
| Нет ключа / Claude не отвечает / таймаут 25 с | `/api/analyze` → `503`, `/api/listings` → `503` | заготовленный ответ |
| Claude дважды ответил не по схеме | `/api/analyze` → `500` | заготовленный ответ |
| Исчерпан суточный лимит `AI_DAILY_LIMIT` | `503` | заготовленный ответ |
| Исчерпан часовой лимит пользователя | `429` | `429` (демо-режим тут не спасает — это защита от злоупотреблений) |
| Claude работает нормально | настоящий ответ | **настоящий ответ** (демо-режим включается только при сбое) |

Значит, `DEMO_FALLBACK=true` можно держать включённым и с рабочим ключом: пока Claude отвечает, ответы настоящие, а при сбое демо не сломается.

### Какие ответы отдаются

**`/api/analyze`** — один из 4 заготовленных наборов из `src/data/demo/`:

| Файл | Что «находится» на фото |
|---|---|
| `sofa.json` | диван, журнальный столик, торшер |
| `dresser.json` | комод IKEA HEMNES, тумбочка |
| `table.json` | обеденный стол из дуба, 2 стула |
| `bed.json` | кровать queen, матрас, ковёр |

Набор выбирается по пути фото: одно и то же фото всегда даёт один и тот же набор. Вещи сохраняются в базу как обычные — их можно редактировать, удалять и считать по ним `/api/estimate`.

**`/api/listings`** — объявление собирается по шаблону, без AI: заголовок из бренда, названия и материала, описание из размеров, состояния, даты и города. Цены — те же (`priceQuick = resaleLow`, `priceMax = resaleHigh`, округление до $5).

### Ограничения демо-режима

- На **любом** фото «находится» одна из 4 заготовленных комнат, а не то, что на фото на самом деле. Для показа жюри используй 4 подготовленных демо-фото (диван, комод, стол, кровать) — так ответы будут правдоподобными.
- Объявления по шаблону звучат проще, чем от Claude.

### Как сделать демо-ответы настоящими (B3.6)

Когда появится ключ:

1. Сфотографируй (или найди) 4 фото: диван, комод, стол, кровать.
2. Прогони каждое через `/api/analyze` с рабочим ключом.
3. Сохрани ответы в `src/data/demo/sofa.json`, `dresser.json`, `table.json`, `bed.json` в том же формате (массив вещей без `id`, `moveId`, `photoPath`, `sentimental`, `userEdited`):

```json
[
  { "category": "sofa", "name": "3-seat grey fabric sofa", "brand": null, "material": "fabric",
    "condition": 3, "widthIn": 84, "depthIn": 36, "heightIn": 34, "volumeCuFt": 65,
    "weightLb": 140, "aiConfidence": 0.9 }
]
```

## Ошибки и что они значат

| Ответ API | Причина | Что делать |
|---|---|---|
| `503 AI is temporarily unavailable…` | нет ключа, сбой Claude, таймаут | вставить ключ или включить `DEMO_FALLBACK=true` |
| `503 Daily AI limit reached` | исчерпан `AI_DAILY_LIMIT` | подождать до следующих суток, поднять лимит или включить демо-режим |
| `429 You can scan up to 30 photos per hour…` | часовой лимит пользователя | подождать час (или очистить куки — для тестов) |
| `429 Up to 60 items per move…` | в переезде уже 60 вещей | удалить лишние вещи |
| `500 Could not read this photo…` | Claude дважды ответил не по схеме | попробовать другое фото |
| `402` на `/api/listings` | переезд не оплачен | оплатить (тестовая карта `4242 4242 4242 4242`) |
| `409` на `/api/listings` | нет оценки или вердикт `SHIP` | сначала Calculate; объявления только для `SELL` и `TOSSUP` |

Подробности ошибки — в терминале с `npm run dev` (строки `[POST /api/analyze] …`) или в Vercel → Logs. В логи пишутся только код и сообщение ошибки, без фото, email и ответов AI.

## Где это в коде

| Файл | Что там |
|---|---|
| `src/lib/ai/client.ts` | клиент Anthropic, модель, таймаут 25 с, `demoFallbackEnabled()` |
| `src/lib/ai/vision.ts` | `analyzePhoto` — распознавание, zod-валидация, один повтор |
| `src/lib/ai/listing.ts` | `generateListing` (Claude) и `templateListing` (шаблон для демо) |
| `src/lib/ai/prompts.ts` | `VISION_PROMPT`, `LISTING_PROMPT` |
| `src/lib/ai/demo.ts` | выбор демо-набора по фото |
| `src/data/demo/*.json` | демо-ответы распознавания |
| `src/lib/ratelimit.ts` | часовые и суточный лимиты (`ai_calls`) |
